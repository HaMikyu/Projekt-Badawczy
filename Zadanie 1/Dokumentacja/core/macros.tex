This document presents the project plan for detecting AI-generated text.
It covers related work, consultations with an expert (dr hab.\ Piotr Hońko)
and with a generative AI system, a brief requirements analysis, project scope,
a preliminary schedule, and a GenAI usage statement.
The minimum success criterion is classification accuracy of at least 51\%
on a chosen test set.
